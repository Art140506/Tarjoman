# ترجمان (Tarjoman)

مترجم چندرسانه‌ای — متن، صدا، تصویر، سند و زیرنویس — با موتور Gemini، به‌صورت یک PWA کاملاً سمت‌کاربر که می‌تواند رایگان روی GitHub Pages میزبانی شود.

## ویژگی‌ها

- **متن** — ترجمه با انتخاب لحن (کتابی / محاوره‌ای / سینمایی) + شنیدن ترجمه با گفتار مصنوعی
- **همزمان** — مکالمه‌ی نوبتی صوتی بین دو زبان (ضبط → رونویسی → ترجمه → پخش صوتی)
- **منابع** — دوربین/تصویر (OCR با بینایی Gemini) و اسناد (PDF / DOCX / TXT، استخراج کاملاً سمت‌کاربر با pdf.js و mammoth.js)
- **زیرنویس** — SRT / VTT / پایه‌ی ASS، با حفظ زمان‌بندی و هشدار CPS (کاراکتر بر ثانیه)
- **تنظیمات** — زبان رابط (فارسی/انگلیسی/عربی/ترکی)، ۵ تم (سیستم، روشن، تاریک، کهربایی، آبی فیروزه‌ای)، مدیریت چند کلید API، انتخاب مدل

زبان‌های مقصد: بیش از ۷۰ زبان رسمی دنیا (`js/langs.js`).

## معماری و نکته‌ی مهم درباره‌ی امنیت کلید

GitHub Pages فقط **میزبانی ایستا** است و بک‌اندی ندارد. بنابراین راهی برای «مخفی کردن واقعی» یک کلید API پشت سرور وجود ندارد مگر یک سرویس جدا (مثل Cloudflare Workers) اضافه کنید. رویکرد این پروژه:

- هر کاربر کلید(های) Gemini خودش را در بخش تنظیمات وارد می‌کند.
- کلیدها با **AES-GCM** (از طریق Web Crypto API مرورگر) و یک **رمز محلی** که خود کاربر انتخاب می‌کند، رمزنگاری و فقط در `localStorage` همان مرورگر ذخیره می‌شوند.
- هر درخواست ترجمه مستقیماً از مرورگر کاربر به `generativelanguage.googleapis.com` می‌رود — هیچ سروری بین این دو نیست.
- می‌توانید چند کلید اضافه کنید؛ اگر یکی به سقف/خطا برسد (۴۲۹/۴۰۱/۴۰۳)، ترجمان خودکار سراغ کلید فعال بعدی می‌رود (چرخش round-robin).

این یعنی امنیت کلید معادل امنیت خودِ دستگاه و مرورگر کاربر است — نه یک راز سرتاسری مخفی از همه.

## استقرار روی GitHub Pages

1. یک مخزن جدید در GitHub بساز و محتویات این پوشه را push کن:
   ```bash
   git init
   git add .
   git commit -m "feat: تارجمان نسخه‌ی اول"
   git branch -M main
   git remote add origin https://github.com/USERNAME/tarjoman.git
   git push -u origin main
   ```
2. در مخزن: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. ورک‌فلوی `deploy.yml` به‌طور خودکار روی هر پوش به `main` اجرا می‌شود.
4. آدرس نهایی: `https://USERNAME.github.io/tarjoman/`

## اجرای محلی

هر سرور استاتیک ساده کافی است، مثلاً:
```bash
python3 -m http.server 8080
```
سپس `http://localhost:8080` را باز کن.

## گرفتن کلید Gemini

از [Google AI Studio](https://aistudio.google.com/apikey) یک کلید API رایگان بساز و در تب «تنظیمات» ترجمان وارد کن.

## نصب روی موبایل/دسکتاپ (PWA)

- **اندروید (Chrome):** روی سایت که باز شد، منو → «افزودن به صفحه‌ی اصلی».
- **iOS (Safari):** دکمه‌ی اشتراک‌گذاری → «Add to Home Screen».
- **دسکتاپ (Chrome/Edge):** آیکون نصب کنار نوار آدرس.

## محدودیت‌های شناخته‌شده / نکات توسعه‌ی بعدی

- **مدل‌های Gemini** به‌سرعت تغییر می‌کنند. نام مدل متن/بینایی و مدل TTS در تنظیمات قابل ویرایش است — اگر نام مدلی منسوخ شد، فقط کافی‌ست در تنظیمات جایگزینش کنی (نیازی به تغییر کد نیست).
- **فرمت صدای ضبط‌شده در تب «همزمان»** به مرورگر بستگی دارد (معمولاً `audio/webm;codecs=opus` در Chrome/Edge/Android، `audio/mp4` در iOS Safari). این فرمت‌ها معمولاً توسط Gemini پذیرفته می‌شوند؛ در صورت خطا، مدل ورودی صوتی را بررسی و در صورت نیاز به‌روزرسانی کن.
- **ASS** فقط خطوط `Dialogue` را ترجمه می‌کند؛ استایل‌ها و افکت‌های پیشرفته (کاراوکه، انیمیشن) دست‌نخورده باقی می‌مانند.
- **گفتار مصنوعی (TTS)** ابتدا از مدل TTS جمینای استفاده می‌کند و در صورت خطا (مثلاً کلید بدون دسترسی به آن مدل)، به‌طور خودکار به گفتار داخلی مرورگر (Web Speech API) برمی‌گردد که کیفیت و پوشش زبانی کمتری دارد.
- برای کلیدهای Gemini، سهمیه‌ی رایگان Google اعمال می‌شود؛ ترجمه‌ی اسناد یا زیرنویس‌های خیلی بزرگ ممکن است به چند کلید یا صبر بین درخواست‌ها نیاز داشته باشد.
